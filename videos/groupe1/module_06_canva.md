# MODULE 6 — Нodi е мој асистент! — Guide Canva Complet

## Infos générales
- Durée totale : 3 min 30 sec
- Nombre de slides Canva : 12
- Voix : IA intégrée Canva (Text-to-Speech)
- Langue voix : Macédonien
- Musique : Ambiance chaleureuse/soir à la maison (style lo-fi doux), volume bas 20%

---

## SETUP CANVA — Avant de commencer
1. Aller sur canva.com → Créer un design → Présentation (16:9)
2. Format : 1920x1080px
3. Police principale : Plus Jakarta Sans Bold (ou Nunito Bold)
4. Couleurs du projet :
   - Bleu principal : #2563EB
   - Blanc : #FFFFFF
   - Texte sombre : #0F172A
   - Vert succès : #16A34A
   - Orange warning : #F97316
   - Doré badge : #FCD34D
   - Bleu très clair (fond modules) : #EFF6FF
