## Comment utiliser ces fichiers

### Étape 1 — Créer le design Canva
1. Va sur canva.com
2. Clique "Créer un design" → "Présentation" → format 1920x1080
3. Pour chaque slide : suis les instructions "🎨 Canva — Instructions visuelles"

### Étape 2 — Ajouter la voix IA
1. Dans Canva, clique sur l'onglet "Audio" (barre gauche)
2. Cherche "Text to speech" ou utilise l'outil IA voix Canva
3. Copie-colle le texte de la section "🎙️ Script voix IA"
4. Choisis une voix naturelle macédonienne si disponible
   (sinon : voix slave/croate comme alternative proche)
5. Ajuste la vitesse à 0.95 (légèrement plus lent pour enfants)

### Étape 3 — Animations
- Utilise le panneau "Anime" dans Canva
- Applique les animations indiquées dans chaque slide
- Pour les délais : Canva → "Présenter" → "Autoplay" → régler durée par slide

### Étape 4 — Export vidéo
1. Clique "Partager" → "Télécharger"
2. Choisir format : MP4
3. Qualité : 1080p
4. Cocher "Inclure les notes" : NON
