# Нodi и светот на ВИ — Formation IA Groupe 1

## Français

### Description
Ce projet génère automatiquement un fichier PowerPoint (`Nodi_Groupe1_Formation_IA.pptx`) contenant l'intégralité du **Groupe 1** de la formation IA « Нodi и светот на ВИ » (pour enfants de 9 à 14 ans).

Le fichier PPTX contient **22 diapositives** couvrant 6 modules :
1. **Module 1** — Нodi се буди *(Qu'est-ce que l'IA ?)*
2. **Module 2** — Нodi е гладен *(Les données : carburant de l'IA)*
3. **Module 3** — Нodi сортира *(Classification)*
4. **Module 4** — Нodi полага испит *(Entraînement vs Test)*
5. **Module 5** — Нodi греши *(Erreurs et confiance)*
6. **Module 6** — Нodi е мој асистент! *(L'IA dans la vie quotidienne)*

### Prérequis
- Python 3.8 ou supérieur
- pip

### Installation
```bash
pip install -r requirements.txt
```

### Exécution
```bash
python generate_pptx.py
```

Le fichier `Nodi_Groupe1_Formation_IA.pptx` sera généré dans le répertoire courant.

### Structure du projet
